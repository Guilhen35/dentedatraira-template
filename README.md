# 🎣 Dente da Traíra · Mídia kit (Template)

Versão de **demonstração** do site oficial e mídia kit de **Matheus Alexandre (Dente da Traíra)**, criador de conteúdo de pesca esportiva. Nome, fotos e números publicados **com autorização** do cliente.

## O que tem

- Números das redes sociais (Instagram, YouTube, TikTok e Kwai)
- Recordes de pesca, vídeos em destaque e carrossel de fotos
- Parceiros e vitrine de produtos
- Painel administrativo (`/admin/admin.html`) para editar números, fotos e produtos

> **Na demonstração:** a senha do painel é `demo` e as alterações ficam salvas só no navegador de quem usa (localStorage). Nada é enviado a servidores.

## Tecnologias

HTML5 · CSS3 · JavaScript (sem frameworks) · Vercel

## Segurança e performance

- Cabeçalhos de segurança em `vercel.json` (CSP, HSTS, X-Frame-Options, nosniff)
- Imagens otimizadas (de 15 MB para menos de 400 KB)
- `noindex` para não competir com o site oficial nos buscadores
